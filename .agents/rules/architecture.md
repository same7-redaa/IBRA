# قواعد تنظيم المشروع (Project Organization Rules)

يجب على الذكاء الاصطناعي (AI) الالتزام التام بالقواعد التالية عند كتابة أو تعديل أي كود في هذا المشروع لضمان سهولة الصيانة والتطوير المستقبلي:

## 1. الهيكلة القائمة على المكونات (Component-Based Architecture)
*   يجب تقسيم أي واجهة مستخدم (UI) إلى مكونات (Components) صغيرة، مستقلة، وقابلة لإعادة الاستخدام.
*   لا يجب وضع كود طويل جداً في ملف واحد. يجب فصل المنطق (Logic) عن واجهة المستخدم (UI).

## 2. التنظيم في مجلدات (Folder Structure)
يجب أن يكون المشروع مقسماً إلى مجلدات واضحة تعكس وظيفتها:
*   `components/`: يحتوي على المكونات العامة المشتركة.
*   `features/` أو `modules/`: تقسيم المشروع حسب الميزات (مثلاً: `products`, `orders`, `shipping`, `users`). كل ميزة تحتوي على مكوناتها، دوالها، وحالتها الخاصة.
*   `utils/` أو `helpers/`: للدوال المساعدة المشتركة.
*   `services/` أو `api/`: لجميع الاتصالات بقواعد البيانات أو واجهات برمجة التطبيقات (APIs).

## 3. التسمية الواضحة (Naming Conventions)
*   استخدام أسماء واضحة ومعبرة باللغة الإنجليزية للملفات، المتغيرات، والدوال.
*   استخدام (PascalCase) للمكونات (مثل `ProductCard.tsx`).
*   استخدام (camelCase) للمتغيرات والدوال (مثل `calculateTotal()`).

## 4. التعليقات والتوثيق
*   يجب إضافة تعليقات قصيرة ومفيدة تشرح "لماذا" تم كتابة الكود المعقد (وليس "ماذا" يفعل الكود البديهي).
*   الاعتماد على أنواع البيانات القوية (TypeScript) لتقليل الحاجة للتعليقات.

## 5. الاستقلالية (Decoupling)
*   يجب أن تكون أقسام النظام (مثل الشحن، الدفع، إدارة المنتجات) مفصولة عن بعضها قدر الإمكان، بحيث يمكن تعديل أو تبديل نظام الشحن دون التأثير على نظام الدفع.

## 6. الثبات على التصميم (Strict UI Consistency)
*   **ممنوع اختراع ستايلات جديدة:** بعد بناء الواجهة واعتماد نظام الألوان (الديزاين سيستم / Tailwind Config)، يُمنع منعاً باتاً اختراع ألوان جديدة، أو استخدام (Inline Styles) عشوائية في المكونات الجديدة.
*   **ممنوع تعديل الأساس:** لا تقم بتعديل الاستايل الأساسي (Global Styles) أو المكونات الرئيسية (Base Components) عند بناء ميزة جديدة لكي لا يتلف التصميم القديم. يجب استخدام نفس المكونات والـ (Classes) المعتمدة مسبقاً للحفاظ على هوية بصرية متطابقة 100%.
